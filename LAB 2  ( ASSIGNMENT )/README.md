
# Hospital Appointment Management System

This lab activity is part of my Software Design & Architecture (SDA) course in the 3rd semester of BS Software Engineering at the University of Azad Jammu and Kashmir (UAJK).

## About the Lab

In this activity, I selected the Hospital Management System as my domain and identified the main conceptual classes used in a hospital appointment system. I also worked on the attributes and methods of three important classes and learned how abstraction and invented software objects are used in software design.

## Tasks Completed

- Selected the Hospital Management System domain.
- Listed 10 conceptual classes.
- Defined attributes and methods for Patient, Doctor, and Appointment.
- Explained abstraction by identifying important and irrelevant information.
- Identified Appointment Controller as an invented software object.

## Concepts Learned

- Conceptual Classes
- Attributes and Methods
- Abstraction
- Invented Software Objects
- Real-World Concepts in Software Design
